## What I do

I build and deliver complete web projects end to end: architecture, frontend, backend, deployment and handover to the client.

Most of my work is **headless**: a WordPress or PHP backend exposing a REST API, with a React, Astro or Next.js frontend on top. The result is a site the client can update on their own, that loads fast and ranks well.

My background is **Industrial Design (Politecnico di Bari)** and years of running my own businesses in Italy and the UK. That means I talk to clients directly, translate a vague brief into a spec, and take responsibility for the thing actually working in production — not just for the code compiling.

I also build **AI and automation** into how I work: agent workflows, MCP connectors and structured prompting to automate the repetitive parts — with the output always verified before it ships.

**Currently:** Web Developer at [Media Aptitude](https://www.media-aptitude.it), a digital agency in Lecce.
**Open to:** Frontend / Full-Stack roles — remote or Puglia-based.

## 🚀 Live in production

Built at Media Aptitude. Each one has a published case study on the agency site.

### [Media Aptitude](https://www.media-aptitude.it) — the agency's own website

The showcase Media Aptitude uses to present itself to its clients — and they handed it to me. Static-first architecture in Astro, built for Core Web Vitals and organic search.

`Astro` `SEO` `Performance` → **[Live site](https://www.media-aptitude.it)**

### [FormEdil](https://gestionale.formedillecce.it/) — enrolment management platform

Digitises the Art. 37 collaboration request forms for a construction training body. Multi-step form, schema-driven validation, server-side PDF generation, and a signed-token flow so applicants can return, download, sign and upload their documents. Custom WordPress plugin with a layered architecture (Controller → Service → Repository), rate limiting and an audit log.

`React.js` `WordPress` `PHP` `REST API` `MySQL` → **[Live site](https://gestionale.formedillecce.it/)** · **[Case study](https://www.media-aptitude.it/lavori/formedil)**

### [Alba Salentina in Sella](https://albasalentina.mcsalentumterrae.it/) — territorial event platform

The digital transformation of a regional event: programme, exhibitors and visitor information, designed mobile-first for people consulting it on the move. UX and UI design, SEO, performance tuning, accessibility and social integration.

`React.js` `WordPress` `CSS` `SEO` → **[Live site](https://albasalentina.mcsalentumterrae.it/)** · **[Case study](https://www.media-aptitude.it/lavori/alba-salentina-in-sella)**

### [Colmac](https://docs.colmac-italia.com/#/) — technical documentation platform

Searchable manual and catalogue library for an industrial machinery manufacturer. Headless architecture: WordPress REST API as the structured content backend with custom taxonomies (product line, machine type), React frontend with combinable filters and dynamic navigation.

`WordPress Headless` `React.js` `PHP` `Bootstrap` → **[Live site](https://docs.colmac-italia.com/#/)** · **[Case study](https://www.media-aptitude.it/lavori/colmac)**

### [Le Mura degli Angeli](https://www.lemuradegliangeli.it) — hospitality site *(independent)*

Full production site for a luxury B&B and historic residence in Salento, designed and built independently end to end. Multi-property structure, gallery, experiences and booking flow, with complete SEO and Open Graph metadata.

`Next.js` `React` `SEO` → **[Live site](https://www.lemuradegliangeli.it)**

**Also shipped:** MotorTour event registration system (PHP · REST · token auth · document upload), coworking space management platform, MariGiaccari.
